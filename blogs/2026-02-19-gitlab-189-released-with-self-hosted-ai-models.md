<p>Today, we are excited to announce the release of GitLab 18.9 with <a href="#gitlab-duo-agent-platform-self-hosted-models-now-available-for-cloud-licenses">GitLab Duo Agent Platform self-hosted models now available for cloud licenses</a>, <a href="#vulnerability-resolution-with-gitlab-duo-agent-platform-beta">vulnerability resolution with GitLab Duo Agent Platform</a>, <a href="#navigate-repositories-with-collapsible-file-tree">navigate repositories with collapsible file tree</a>, <a href="#include-cicd-inputs-from-a-file">include CI/CD inputs from a file</a>, <a href="#new-security-dashboard-chart-vulnerabilities-by-age">new security dashboard chart: vulnerabilities by age</a> and much more!</p>

<p>New to GitLab Duo? <a href="#gitlab-duo-agent-platform-available-in-ultimate-trials">Ultimate with GitLab Duo Agent Platform trials</a> are now available for both GitLab.com and GitLab Self-Managed.</p>

<p>These are just a few highlights from the 25+ improvements in this release. Read on to check out all of the great updates below.</p>

<p>To the wider GitLab community, thank you for the 530+ contributions you provided to GitLab 18.9!
At GitLab, <a href="https://about.gitlab.com/community/contribute/">everyone can contribute</a> and we couldn't have done it without you!</p>
