<p>Today, we are excited to announce the release of GitLab 18.6 with a <a href="#the-new-gitlab-ui-designed-for-productivity">new UI designed for productivity</a>, <a href="#exact-code-search-in-limited-availability">exact code search in limited availability</a>, <a href="#cicd-components-can-reference-their-own-metadata">CI/CD Components metadata reference capabilities</a>, <a href="#gitlab-security-analyst-agent-available-as-a-foundational-agent">GitLab Security Analyst Agent available as a foundational agent</a> and much more!</p>
