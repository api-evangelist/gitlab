GitLab 19.1 was released on June 18, 2026, with secret false positive detection in the GitLab Duo Agent Platform now generally available, an always-on availability mode for Duo, and support for GPT-5.2 and GPT-5.3 Codex models in Code Review Flow. The release adds stacked merge requests in the UI, automatic Code Owner reviewer assignment, 19 compliance framework templates (ISO 27001:2022, SOC 2, FedRAMP, NIST, CIS, TISAX), a generally available Security Manager role, and SARIF 2.1.0-compliant scanner integration.
