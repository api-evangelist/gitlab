<p>Today, we are excited to announce the release of GitLab 18.8 with <a href="#gitlab-duo-agent-platform-now-generally-available">GitLab Duo Agent Platform now generally available</a>, <a href="#gitlab-duo-planner-agent-now-generally-available">GitLab Duo Planner Agent</a>, <a href="#gitlab-duo-security-analyst-agent-now-generally-available">GitLab Duo Security Analyst Agent</a>, <a href="#auto-dismiss-irrelevant-vulnerabilities-with-vulnerability-management-policies">auto-dismiss irrelevant vulnerabilities</a>, and much more!</p>

<p>These are just a few highlights from the 10+ improvements in this release. Read on to check out all of the great updates below.</p>

<p>To the wider GitLab community, thank you for the 119 contributions you provided to GitLab 18.8!
At GitLab, <a href="https://about.gitlab.com/community/contribute/">everyone can contribute</a> and we couldn't have done it without you!</p>
